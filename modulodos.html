Acceso a Datos

Explica cómo almacenar, organizar y consultar información de forma eficiente. Se trabaja con modelos de datos, diseño de bases de datos relacionales y el lenguaje SQL para crear, modificar y consultar datos.

Desarrollo de Interfaces

Introduce el funcionamiento interno de los ordenadores y sistemas operativos. El alumno aprende a instalar, configurar y mantener sistemas, gestionar usuarios, permisos y recursos, y comprender cómo se comunican los equipos en red.

IPE II

Desarrolla las bases de la lógica de programación y la resolución de problemas. Se aprende a crear programas estructurados, trabajar con funciones, estructuras de datos y aplicar buenas prácticas de desarrollo.

Programación de Servicios y Procesos

Crear y gestionar procesos, hilos y servicios que trabajan simultáneamente dentro de una aplicación o entre varias aplicaciones.

Programación Multimedia y Dispositivos Móviles de Marcas

Introduce lenguajes como HTML, XML y JSON, así como herramientas para estructurar, transformar y presentar información. También se estudian tecnologías web básicas y sistemas de gestión de contenidos.
